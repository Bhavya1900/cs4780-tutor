# AI Usage

## Overview

AI tools were used as development assistance during this project, but the project was not entirely generated by AI.

Approximately half of the implementation was developed independently by me. I handled a significant portion of the frontend structure, basic React components, styling, data integration, UI behavior, and the initial project setup myself.

I used AI more heavily for the technically difficult parts of the project, particularly the chat-generation/streaming workflow, complex state management, debugging, persistence architecture, and later feature integration and UI refinement.

The final implementation was reviewed, integrated, tested, and committed by me.

---

## My Contribution

I independently worked on a substantial part of the project, including the easier and foundational components and features.

My work included areas such as:

- Initial React + Vite project setup
- Basic component structure
- JSX structure
- Initial application layout
- CSS styling and responsive design
- Basic course/tutor UI
- Integration of the supplied course data
- Initial data-layer organization

- Reviewing and deciding which additional features were appropriate
- Final product and UI decisions

I also reviewed the implementation throughout the project and made decisions about what should and should not be included.

---

## Where AI Assistance Was Most Useful

AI assistance was primarily used for the more complex portions of the implementation.

### 1. Chat generation and streaming

The streaming tutor experience was one of the more technically difficult parts of the project.

AI assistance was used to help with:

- asynchronous streaming logic
- `for await` streaming loops
- React streaming state
- thinking/loading states
- partial responses
- AbortController-based cancellation
- Stop behavior
- Retry behavior
- mid-stream error handling

The supplied `mock-stream.mjs` and `responses.json` remained the source of truth for the deterministic tutor behavior.

---

### 2. Complex state management

AI was used to reason about interactions between:

- chat state
- streaming state
- conversation persistence
- New Chat
- chat history
- selected conversations
- Study Trail
- course progress
- saved concepts
- Learning Companion

This was particularly useful because these features interact with each other and needed to remain stable without introducing a backend.

---

### 3. Debugging

AI assistance was used during debugging and code review to identify issues such as:

- streaming cancellation architecture
- state synchronization
- persistence edge cases
- citation resolution
- responsive overflow
- Markdown/GFM rendering
- mobile layout behavior
- accessibility issues

One notable example was identifying an AbortController mismatch in the streaming implementation and restructuring the controller ownership so the Stop button could actually cancel the active stream.

---

### 4. Advanced feature integration

AI helped implement and connect some of the later, more complex product features:

- persistent multiple conversations
- New Chat
- Course Progress
- Study Trail improvements
- Continue Learning
- Saved Concepts
- Learning Companion
- citation interactions

These features were implemented on top of the application architecture rather than replacing the original project.

---

### 5. UI refinement

AI was also used as a design and review partner for the later visual refinement.

This included suggestions and implementation assistance for:

- sidebar hierarchy
- course progress presentation
- learning companion cards
- responsive layouts
- focus states
- interaction states
- spacing and typography
- visual hierarchy
- mobile behavior

The final visual direction and feature choices were reviewed and selected by me.

## AI Tools Used

The main AI tools used during development were:

- **Claude Sonnet via Antigravity** — primarily for repository inspection, complex implementation, debugging, and feature integration
- **Gemini 3.6** — used during earlier development
- **ChatGPT** — used for architecture discussions, debugging, planning, code review, feature prioritization, and UI/product decisions

Different tools were used at different stages depending on the task.

## How I Used AI

My workflow was generally:

```text
Understand the requirement
        ↓
Build simpler parts myself
        ↓
Identify technically difficult portions
        ↓
Use AI to reason about / implement those portions
        ↓
Review the generated implementation
        ↓
Run and test locally
        ↓
Fix issues
        ↓
Commit incrementally
